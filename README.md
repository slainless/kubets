# Caverns and Chasms & Vanilla Backport Copper Compatibility

Version: `1.21.1`

## Background

Both C&C and VB add copper sets to the game. However, VB implementation is closest to how it is actually implemented and how it looks in the latest version of the game.

So in this example, we disable some overlapping contents from C&C, especially the recipes to make
those items inaccessible.
